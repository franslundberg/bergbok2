# Source evidence

The existing Bergbok demos were inspected as characterization evidence and
were not rewritten or normalized during this implementation.

`source-baseline.json` records the relevant source-set hashes and test results
observed immediately before extraction. The hash is a local provenance aid,
not a portable source archive: its calculation includes absolute file paths.

The new modules do not import private files from the demos. The retained demos
remain independent evidence clients until equivalent Start, Import, ordinary,
payroll handoff, and lifecycle scenarios have passed through the new public
interfaces.
